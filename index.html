Sanfonas (Collapse / Accordions)

Como funciona o pure CSS Collapse?

Utilizamos a pseudo-classe :checked de um checkbox oculto para expandir e colapsar o contêiner dinamicamente com grid-template-rows.

Posso ter múltiplas abas abertas?

Sim! Ao utilizar checkboxes individuais, cada componente age de forma autônoma permitindo manter vários expandidos de uma vez.

Exibir Código HTML (Modal e Dropdown)

<!-- Modal Pure CSS -->
<input type="checkbox" id="demo-modal" class="modal-toggle" />
<div class="modal">
  <div class="modal-box">
    <h3 class="font-bold text-lg">Olá!</h3>
    <p class="py-4">Conteúdo do modal...</p>
    <div class="modal-action">
      <label for="demo-modal" class="btn">Fechar</label>
    </div>
  </div>
</div>

<!-- Tooltip -->

Exibir Código HTML (Layout Responsivo)

<!-- Grid que muda de colunas dependendo do tamanho da tela -->
<div class="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-6">
  <div class="card">...</div>
  <div class="card">...</div>
  <div class="card">...</div>
</div>

<!-- Elemento que fica oculto no celular e flex no computador -->
<div class="hidden md:flex justify-between items-center">
  <span>Apenas telas médias ou maiores</span>
</div>

Classes Utilitárias Geradas

As classes abaixo possuem suporte completo a variantes de tela (sm:, md:, lg:, xl:, 2xl:) e possuem a tag !important para garantir precedência.

Tipo Exemplos de Classe Descrição
Espaçamento p-4, mx-2, py-8, mt-auto, md:p-8 Paddings e margins em escalas de 0.25rem a 6rem.
Layout Display flex, grid, hidden, block, md:hidden Configuração do display box-model.
Posições Flex items-center, justify-between, flex-col Alinhamento, justificação e direção de caixas flexíveis.
Grid Template grid-cols-2, col-span-3, gap-4, lg:grid-cols-4 Divisão de grades de 1 a 12 colunas e espaçamento entre células.
Tipografia text-xl, font-bold, text-center, md:text-4xl Tamanho da fonte, espessura e alinhamento do texto.
Cores e Bordas bg-primary, text-neutral-content, border-error Aplicações rápidas das cores semânticas do tema ativo.
